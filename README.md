# oyna-oqy

Развивающие игры на казахском и русском языках для детей 3–6 лет. Весь интерфейс построен на картинках, анимации и голосе, текста для ребёнка нет.

Нет бэкенда, регистрации, аналитики и сторонних запросов. Все данные хранятся на устройстве: в `localStorage` записаны только язык и звук.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev        # http://localhost:5173 (и по локальной сети: адрес выводится в консоль)
```

Чтобы открыть на телефоне, подключите его к той же Wi-Fi-сети и введите адрес `Network:` из консоли.
Сервис-воркер и установка на главный экран работают только в сборке (`npm run build && npm run preview`)
и только по HTTPS или на `localhost`.

## Сборка

```bash
npm run build      # проверка типов + сборка в dist/
npm run preview    # локальный просмотр сборки (http://localhost:4173)
```

Содержимое `dist/` можно выложить на любой статический хостинг (Netlify, GitHub Pages, nginx).
Для SPA-маршрутов (`/cards/animals` и др.) сервер должен отдавать `index.html` на неизвестные пути.
После первой загрузки приложение работает без интернета: код, картинки и иконки кэшируются сразу,
аудио кэшируется при первом проигрывании.

```

```

## Как работает озвучка

Для каждой фразы или предмета по порядку:

1. Аудиофайл из `content.json` (`audio.kk` / `audio.ru`) воспроизводится через Howler. Файл грузится только при первом обращении.
2. Если файла нет или он не загрузился, текст из `label.kk` / `label.ru` читает `speechSynthesis` голосом `kk-KZ` / `ru-RU`.
3. Если в системе нет голоса для этого языка, приложение работает без звука и не падает.

Казахский системный голос есть далеко не везде. В настройках под языком появится пометка, если голоса нет.
Для казахского языка запишите аудиофайлы, это главный путь.

До первого касания браузер блокирует звук. Первое касание любого места разблокирует его, и звучит приветствие.

## Как добавить контент

Все данные хранятся в `src/data/content.json`. После правки перезапуск не нужен: в режиме `dev` страница обновится сама.

### Предмет (карточку)

1. Положите картинку в `public/assets/img/`, например `public/assets/img/kymyz.svg`.
   Подойдут SVG, PNG и WebP. Лучше брать квадратную картинку от 512×512, сжатую (SVG до 10 КБ, WebP до 60 КБ).
2. Положите озвучку в `public/assets/audio/kk/kymyz.mp3` и `public/assets/audio/ru/kymyz.mp3`.
   Подойдут MP3, M4A/AAC и OGG. Обрежьте тишину по краям, 64–96 кбит/с моно достаточно.
   Файлов пока нет? Ничего страшного: прочитает синтезатор речи.
3. Добавьте объект в массив `items` нужной категории:

```json
{
  "id": "kymyz",
  "image": "/assets/img/kymyz.svg",
  "audio": { "kk": "/assets/audio/kk/kymyz.mp3", "ru": "/assets/audio/ru/kymyz.mp3" },
  "label": { "kk": "қымыз", "ru": "кумыс" }
}
```

`id` должен быть уникальным во всём файле, латиницей, без пробелов. В «Найди пару» по нему ищется совпадение.

### Категорию

Добавьте объект в массив `categories`:

```json
{
  "id": "toys",
  "icon": "/assets/img/cat-toys.svg",
  "color": "#3BB7A6",
  "audio": { "kk": "/assets/audio/kk/cat-toys.mp3", "ru": "/assets/audio/ru/cat-toys.mp3" },
  "label": { "kk": "Ойыншықтар", "ru": "Игрушки" },
  "items": [ ... ]
}
```

Категория сразу появится в «Карточках» и в «Найди пару».
Для режима «Найди» желательно не меньше 3 предметов. Если их меньше, недостающие варианты берутся из других категорий.

### Заменить картинку или звук

Положите файл с тем же именем поверх старого, код менять не нужно.
Можно сменить и формат (например, `.svg` на `.webp`), но тогда поправьте путь в `content.json`.

### Фразы (приветствие, похвала, инструкции)

Фразы лежат в `phrases` в `content.json`, аудио к ним ищется по путям `public/assets/audio/{kk,ru}/phrase-<id>.mp3`.

### Заглушки

`npm run gen:img` заново создаёт SVG-заглушки в `public/assets/img/`.
**Скрипт перезаписывает файлы с теми же именами.** Если вы уже положили настоящие картинки, не запускайте его.
`npm run gen:icons` делает PNG-иконки PWA из `public/icon.svg`.

## Настройки

На главном экране в углу есть шестерёнка. Чтобы открыть настройки, удерживайте её 3 секунды, по кругу при этом бежит индикатор.
В настройках выбираются язык голоса (по умолчанию казахский) и звук (вкл/выкл).

## Решения по ТЗ

- В списке элементов юрты указана «сама». Я трактовал это как **саба** (кожаный сосуд для кумыса).
  Если имелось в виду другое, поправьте `id` и `label` в `content.json` и картинку `saba.svg`.
- Кошма по-казахски записана как «киіз».
- В «Найди пару» на уровне с 4 или 6 парами в маленьких категориях (инструменты: 3 предмета, одежда: 5)
  недостающие пары добираются из других категорий.
- Порядок сборки юрты: кереге, уық, шаңырақ, туырлық.
- Звуки «верно», «переворот» и «праздник» синтезируются WebAudio, звуковых файлов для них не нужно.
